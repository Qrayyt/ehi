# EHI!

Личное пространство с минимальной домашней страницей и полноценным сайтом вымышленного персонального кинотеатра **EHI! CINEMA** по адресу `/cinema`.

## Запуск

```bash
npm install
npm run dev
```

## Что внутри

- афиша и выбор даты/сеанса;
- карточка фильма;
- интерактивная схема зала;
- оформление бесплатного персонального приглашения;
- готовый билет и раздел «Мои билеты»;
- адаптивная вёрстка для телефона, планшета и десктопа.

Демо-билет: «Дюна: Часть вторая», Ева Трубникова, 14.11.2026, зал 3, ряд 1, место 1. Платёжная система намеренно не подключена.
