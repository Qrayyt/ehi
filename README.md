# EHI!

Личное пространство с минимальной домашней страницей и полноценным сайтом вымышленного персонального кинотеатра **EHI! CINEMA** по адресу `/cinema`.

## Запуск

```bash
npm install
npm run dev
```

## GitHub Pages

Публикация выполняется автоматически workflow-файлом `.github/workflows/deploy-pages.yml`. Он собирает Vite-приложение с базовым путём `/ehi/`, добавляет SPA-fallback и публикует папку `dist`.

## Что внутри

- афиша из шести фильмов и сериалов с настоящими постерами;
- подробные карточки произведений;
- запрос желаемой даты и времени персонального показа;
- интерактивная схема зала с выбором до четырёх мест;
- бронирование за поцелуи без настоящего списания;
- готовый билет и раздел «Мои билеты»;
- адаптивная вёрстка для телефона, планшета и десктопа.

Стоимость хранится числом: одно место стоит 5 поцелуев. Интерфейс правильно склоняет валюту и не содержит реальных платёжных инструментов. Постеры загружены из каталога TMDB и хранятся локально в `public/posters`.
